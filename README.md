# Jarurat Care 🩺

A responsive React web application for managing patients and viewing a gallery. Built with **React**, **Redux**, **Tailwind CSS**, **React Router**, and **Vite**.  

---

## Features

- Responsive layout for mobile and desktop using **Tailwind CSS**
- User management with **Redux** for state management
- Dynamic **Gallery** component with search and filter functionality
- Individual **SelectedUser** view with detailed information
- Smooth client-side routing with **React Router v6**
- Easy deployment with **Vercel**

---

## Tech Stack

- **Frontend:** React (Vite)
- **State Management:** Redux Toolkit
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Deployment:** Vercel
